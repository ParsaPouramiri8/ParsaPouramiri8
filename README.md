<summary>About these statistics</summary>

Updated daily by GitHub Actions. Age uses April 13, 2008 and the Asia/Tehran calendar date.

- Repos: all public repositories owned by this account, including forks.
- Stars: stars on owned public repositories, excluding forks.
- Contributed: public repositories owned by others with recent contributions reported by GitHub (roughly the past year; includes commits, issues and pull requests).
- Commits: unique, non-merge commits attributed by GitHub to this user, reachable from the default branches of owned public non-fork repositories. Not an all-GitHub contribution total.
- Lines of Code: **net changed text lines** (additions minus deletions) in those same commits. Green and red show cumulative additions and deletions. This includes documentation and other text, and is not a count of source code currently owned or a measure of programming skill.
- Private repositories, non-default branches and commits not linked to this GitHub identity are excluded.
- A dash means the value has not been fetched. On an API failure, the last successful statistics and their timestamp are retained.
